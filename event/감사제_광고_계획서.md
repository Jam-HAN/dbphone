## 2. UTM 규약 (ad 시스템 추적 — 코드 검증 완료)

ad 시스템은 `external_requests.data.utm_*` + GA4 UTM으로 채널/캠페인을 귀속합니다(`UTM_TO_CHANNEL`, `matchActivationForRequest` 30일 윈도우). **모든 광고 링크에 아래 UTM을 반드시 부착.**

- **캠페인 슬러그**: `gamsa_jun_2026`  → `lib/campaign-labels.ts`의 `CAMPAIGN_LABELS`에 `gamsa_jun_2026: '감사제 - 6월 V1'` 등록 필요 (요청 시 처리)
- **utm_source 값 (UTM_TO_CHANNEL 인식 키)**: Meta=`meta`, Google=`google-ad`, 네이버=`naver-ad`

복붙용 랜딩 URL (랜딩 = `https://dbphone.co.kr/event/`) — **채널별 1개로 통일**.
`utm_content`는 랜딩 폼이 적재·추적하지 않으므로(우리 attribution은 utm_source/medium/campaign만 사용) **생략**. Meta는 배치(피드/릴스/스토리)를 자체 리포트로 구분하니 배치별 URL 불필요.

```
Meta     https://dbphone.co.kr/event/?utm_source=meta&utm_campaign=gamsa_jun_2026
Google   https://dbphone.co.kr/event/?utm_source=google-ad&utm_campaign=gamsa_jun_2026
네이버    https://dbphone.co.kr/event/?utm_source=naver-ad&utm_campaign=gamsa_jun_2026
당근     https://dbphone.co.kr/event/?utm_source=karrot-ad&utm_campaign=gamsa_jun_2026
```
당근 전환추적 픽셀(`SubmitApplication`)은 랜딩에 설치 완료. `karrot-ad`는 ad 시스템 `UTM_TO_CHANNEL`에 '당근_광고'로 매핑됨.

> ⚠️ `utm_source`(meta/google-ad/naver-ad)는 **채널마다 반드시 달라야** ad 시스템이 채널을 구분(`/platforms`·일일리포트). 3채널을 완전 동일 URL 하나로 합치면 채널 비교 불가.

> ⚠️ Meta Advantage+ 소재는 `url_tags`가 API로 안 읽히는 경우가 있음 → **광고세트 "URL 매개변수" 칸에 직접 입력**하고, 자동 인식 안 되면 `CAMPAIGN_LABELS` 슬러그 매핑으로 보정됨.

## 4. 채널별 세팅 가이드

### 4-1. Meta (인스타그램 + 페이스북) — 주력
- **목표**: 전환(리드) — 픽셀 `Lead` 이벤트(상담폼 제출/카카오 클릭) 기준. 초반 학습 부족하면 **트래픽**으로 시작 후 전환 전환.
- **광고세트(타겟)**
  - 지역: 장지본점(송파구 장지동)·명일직영점(강동구 명일동) **반경 3~5km** + 위례·하남 미사 포함 고려
  - 연령: 25~59 / 전체 성별
  - 노출위치: Advantage+ 자동(피드+릴스+스토리). 소재 3종 모두 투입.
- **소재/문구 (1차 카피)**
  - 1차 헤드라인: `삼성 20% 보답 + 대박통신 10만원 보답, 6월 감사제`
  - 본문: `갤럭시 S26·울트라·폴드7 개통 시 출고가 20% 온누리상품권 + 10만원 보답까지. 휴대폰·인터넷·TV 결합 최대 설계. 20년 통신 전문가 대박통신.`
  - CTA 버튼: `더 알아보기` (랜딩) — 매장방문 강조 시 `길찾기`
- **A/B**: 소재 1:1 vs 9:16, 헤드라인(혜택강조 vs 결합강조) 2종

### 4-2. Google Ads — 상세 세팅

**A. 전환 추적 먼저 (필수, 광고 만들기 전에)**
1. ads.google.com 로그인 → 우상단 **도구 및 설정 > 측정 > 전환**.
2. GA4 연동이 더 쉬움: **도구 > 설정 > 연결된 계정 > Google Analytics(GA4)** 연결(속성 `536785067`). 연결 후 **전환 > 새 전환 > 가져오기 > GA4** → 이벤트 **`event_intake_submit`**(랜딩 폼 제출 시 발사)를 전환으로 가져오기. ← 이게 "문의 전환".
3. 전환값/횟수: "전환당 1회", 카테고리=리드.

**B. 검색 캠페인**
1. **새 캠페인 > 목표: 리드 > 캠페인 유형: 검색**.
2. 전환목표: 위 `event_intake_submit`만 체크.
3. 입찰: 초기엔 **전환수 최대화**(데이터 쌓이기 전 타깃CPA 금지). 일예산 적음 → 클릭당 상한 우려 시 **클릭수 최대화 + 최대CPC 상한**으로 시작도 가능.
4. **위치**: 송파구·강동구 + 위례/하남미사 반경. (고급검색으로 장지본점·명일점 좌표 반경 ~5km 지정 가능). 언어 한국어.
5. **키워드**(일치검색/구문검색 위주, 소액이라 광범위 제외):
   - 지역+의도: `송파 휴대폰 성지`, `장지동 휴대폰`, `명일동 휴대폰`, `가락시장 휴대폰`, `강동 휴대폰 싸게`
   - 모델: `갤럭시 S26 개통`, `갤럭시 S26 사전예약`, `폴드7 가격`
   - 혜택: `휴대폰 결합 할인`, `온누리상품권 휴대폰`, `휴대폰 보조금 많은 곳`
   - **제외 키워드**: `중고`, `수리`, `유심`, `알뜰폰`, `자급제`(원치 않으면), `채용`
6. **반응형 검색광고(RSA)** 헤드라인 15개/설명 4개 예:
   - 헤드라인: `6월 감사제 삼성 20% 보답` / `대박통신 10만원 보답` / `장지·명일 직영점` / `갤럭시 S26·폴드7 개통` / `휴대폰+인터넷+TV 결합` / `20년 통신 전문가` / `온누리상품권 최대 42만원` / `당일 개통 상담`
   - 설명: `삼성 20% 온누리상품권 + 대박통신 10만원 보답. 6.8~4주 한정.` / `송파 장지 본점·강동 명일 직영점. 무료 상담 1분.`
7. **광고 확장(전부 추가, 무료·CTR↑)**: 사이트링크(혜택보기/매장안내/상담신청), 콜아웃(2년 무상교체·중고폰 매입·당일개통), 전화번호(02-443-6011), 위치(GBP 연결).
8. **최종 URL**: `https://dbphone.co.kr/event/`  **추적 템플릿(계정/캠페인 설정 > 추적 템플릿)**: `{lpurl}?utm_source=google-ad&utm_campaign=gamsa_jun_2026` ← 이러면 모든 광고에 UTM 자동 부착.

**C. PMax(실적 최대화) — 매장 방문 (선택, GBP 있을 때만)**
1. 먼저 **Google 비즈니스 프로필(GBP)** 장지·명일 등록/인증 + Ads에 연결.
2. 새 캠페인 > 목표: **매장 방문 및 프로모션** > PMax. 자산그룹에 4:5/9:16 이미지(감사제 PNG), 로고, 헤드라인/설명(위 RSA 재활용), 최종URL 동일.
3. 소액예산이면 검색만 먼저 돌리고 PMax는 2주차에 추가 권장.
